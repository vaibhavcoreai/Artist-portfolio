# Deepak Patil | Fine Art Studio

A premium, high-performance portfolio for Solapur-based fine artist **Deepak Patil**. This platform is designed to showcase a curated collection of contemporary fine art with a focus on luxury aesthetics and direct-to-artist connectivity.

## ✨ Key Features

- **Luxury UI/UX**: A bespoke, dark-mode design using custom typography and smooth Framer Motion animations.
- **Dynamic Gallery**: High-performance masonry layout with interactive Lightbox and detail views.
- **Direct Connect**: Integrated WhatsApp and Phone calling hooks for instant art inquiries.
- **Admin Dashboard**: Secure management suite for uploading artwork, managing leads, and tracking studio metrics.
- **Mobile Optimized**: Responsive design tailored for collectors browsing on high-end mobile devices.
- **Secure Backend**: Built on Supabase for robust data management and storage.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS
- **Motion**: Framer Motion
- **Backend/Database**: Supabase
- **Image Hosting**: Supabase Storage
- **Routing**: React Router DOM v6



## 🔒 Security

This project follows strict security practices. Environment variables are managed via `.env` (excluded from git), and sensitive actions like artwork deletion require administrative authentication.
